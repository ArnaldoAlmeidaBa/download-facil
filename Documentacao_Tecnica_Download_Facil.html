1. Visão Geral e Princípios Arquiteturais

1.1. Propósito do Sistema

O Download Fácil é uma solução local projetada para resolver a sobrecarga cognitiva e a desorganização crônica em pastas de recebimento de arquivos (com foco inicial na pasta padrão Downloads do sistema operacional). O software analisa, extrai dados internos, classifica o tipo e o assunto, calcula o grau de confiança das evidências e sugere o direcionamento para pastas de destino pré-autorizadas.

🛡️ Princípio Safety-First & Privacidade LGPD
O sistema adota o paradigma local-first. Nenhum arquivo, metadado ou trecho de texto é enviado para a nuvem ou servidores externos. Todas as operações operam sob isolamento local estrito, garantindo total conformidade com a LGPD e políticas rígidas de sigilo institucional.

1.2. Pilares Arquiteturais

  • Execução com Dry-Run Padrão: Antes de qualquer alteração física, o sistema realiza uma varredura completa e auditável, registrando as decisões em logs CSV e compilando um painel visual para homologação.
  • Supervisão Humana Ativa (Human-in-the-Loop): A automação não substitui a responsabilidade do usuário. As regras geram recomendações transparentes com indicação explícita dos termos e sinais textuais que sustentam cada decisão.
  • Prevenção Determinística de Sobrescrita: Em caso de movimentação para uma pasta onde já exista arquivo homônimo, o motor aplica sufixação incremental automática (_1, _2), eliminando o risco de perda acidental de dados.
  • Capacidade Transacional de Reversão (Undo): Toda ação física realizada na sessão é empilhada em memória, permitindo reversão imediata ao local de origem com um único clique.

2. Estrutura de Pacotes e Componentes

A arquitetura do Download Fácil foi modularizada em pacotes com responsabilidades estritas e desacopladas sob o diretório src/:

Pacote / Módulo Responsabilidade Principal Principais Funções / Saídas
src/config.py Configurações globais, limites e resiliência de caminhos. carregar_perfil(), classificar_tipo(), detecção dinâmica de usuário e pastas padrão.
src/readers/ Extratores especializados por formato técnico de arquivo. Leitores de TXT, DOCX, PDF (pypdf), XLSX (openpyxl), XLS (xlrd), PPTX e conversão Base64 para mídia.
src/rules/ Motor de inferência, heurística e governança. normalizar(), identificar_tipo_documental(), analisar_assunto(), avaliar_destino_territorio().
src/logging/ Auditoria determinística e registro histórico em disco. preparar_log(), registrar_decisao() em arquivos CSV codificados em UTF-8 com BOM.
src/actions/ Execução controlada de efeitos colaterais no filesystem. mover_arquivo_seguro(), gerar_caminho_sem_colisao(), desfazer_ultima_movimentacao().
src/server.py Microservidor HTTP nativo para o painel no navegador. Endpoints REST locais (/api/mover, /api/desfazer, /api/reanalisar) na porta 8080.
src/dashboard/ Compilação e apresentação da interface do usuário. gerar_painel_html() com injeção de modais, previews e scripts de disparo assíncrono.
src/core.py Pipeline de orquestração e interface de linha de comando. analisar_arquivo(), executar_orquestracao(), suporte a argumentos CLI (--servidor, --apenas-analise).

3. Especificação das Interfaces e API REST Local

Quando iniciado em modo interativo (comportamento padrão ao dar duplo clique no executável ou via argumento --servidor), o sistema inicializa um servidor HTTP nativo restrito a http://127.0.0.1:8080/.

3.1. Catálogo de Endpoints

POST /api/mover

Executa a movimentação física controlada de um arquivo da origem para o diretório de destino homologado.

// Requisição (JSON)
{
  "origem": "C:\\Users\\ALUNO - CETI\\Downloads\\Oficio_01.pdf",
  "destino": "C:\\Users\\ALUNO - CETI\\Documents\\Revisar"
}

// Resposta com Sucesso (200 OK)
{
  "sucesso": true,
  "origem": "C:\\Users\\ALUNO - CETI\\Downloads\\Oficio_01.pdf",
  "destino": "C:\\Users\\ALUNO - CETI\\Documents\\Revisar\\Oficio_01.pdf",
  "nome_final": "Oficio_01.pdf"
}

POST /api/desfazer

Reverte a última movimentação registrada na pilha de auditoria em memória, restaurando o arquivo ao local de origem.

// Resposta (200 OK)
{
  "sucesso": true,
  "arquivo_restaurado": "C:\\Users\\ALUNO - CETI\\Downloads\\Oficio_01.pdf",
  "mensagem": "Arquivo restaurado para: C:\\Users\\ALUNO - CETI\\Downloads\\Oficio_01.pdf"
}

POST /api/reanalisar

Dispara nova varredura e reanálise dos arquivos presentes na pasta de entrada.

// Resposta (200 OK)
{
  "sucesso": true,
  "total": 64
}

5. Guia de Manutenção e Extensibilidade

5.1. Adição de Novas Regras Documentais

Para cadastrar novos tipos documentais reconhecidos pelo motor, insira a definição em src/rules/classifiers.py: 

REGRAS_TIPO_DOCUMENTAL.append({
    "tipo_documental": "CONTRATO_PRESTACAO_SERVICOS",
    "sinais": [
        "contrato de prestacao de servicos",
        "contratante",
        "contratada",
        "clausula primeira",
        "foro da comarca"
    ],
    "sinais_fortes": [
        "contrato de prestacao de servicos",
        "clausula primeira"
    ],
    "minimo_sinais": 3
})

5.2. Adição de Novos Extratores de Formato

  1. Crie o extrator em src/readers/novo_reader.py respeitando o limite máximo MAX_TEXTO.
  2. Cadastre a extensão suportada no dicionário LEITORES em src/readers/__init__.py.
  3. Execute o comando pytest no terminal para assegurar que nenhuma regressão foi introduzida.
